## How to get started / Explore our work
1. Browse repositories pinned to the profile or the Projects section.
2. Check each repo's README for setup and contribution instructions.
3. For most projects:
   - Clone: `git clone https://github.com/developmentepicinfocus/<repo>.git`
   - Install: follow repo-specific instructions (usually `npm install` / `pip install -r requirements.txt`)
   - Run tests: `npm test` / `pytest`
